## 4. 问题说明

当前显示错乱的原因：
- 地图数据引用的 tile ID 对应原始素材图片的特定位置
- 替换后的素材图片内部 tile 排列不同
- 例如: 原图 tile#1 是地板，但替换后 tile#1 变成了椅子

解决方案：
1. 获取原始 tileset 图片文件
2. 或用 Tiled 软件打开 `references/office-agent.tmx` 重新映射
